# Phrases by situation

Format: English · Japanese · romaji · tag · note. `[X]` marks a fill-in slot. All Japanese gets a native-speaker check after the build. Default to polite (desu/masu) forms.

Priority marks for the MVP set: ★ = must ship.

## Essentials (every situation)

| English | Japanese | Romaji | Tag | Note |
| --- | --- | --- | --- | --- |
| ★ Excuse me / sorry / (to get attention) | すみません | Sumimasen | [N][T] | The all-purpose opener. Say it before any question. |
| ★ Thank you | ありがとうございます | Arigatou gozaimasu | [N] | Add a small nod. |
| Thank you (Kyoto/Kansai) | おおきに | Ookini | [K] | Optional. Used mostly by older shopkeepers. |
| ★ Please (handing something over, or asking for it) | お願いします | Onegaishimasu | [N] | |
| ★ Do you speak English? | 英語は話せますか？ | Eigo wa hanasemasu ka? | [N][T] | Younger staff often understand English but won't offer it first. |
| ★ I don't understand | わかりません | Wakarimasen | [T] | Not rude. It invites them to slow down or point. |
| ★ One more time, please | すみません、もう一度お願いします | Sumimasen, mou ichido onegaishimasu | [N] | |
| No thank you / I'm fine | 大丈夫です | Daijoubu desu | [N] | Polite way to decline a bag, a receipt, or help. |
| ★ Where is the bathroom? | トイレはどこですか？ | Toire wa doko desu ka? | [N][T] | |
| ★ How much is it? | いくらですか？ | Ikura desu ka? | [N][T] | |
| What is this? | これは何ですか？ | Kore wa nan desu ka? | [T] | Point at the menu item or thing. |
| Where is [X]? | [X]はどこですか？ | [X] wa doko desu ka? | [N] | |
| Where am I? (pointing at a map) | ここはどこですか？ | Koko wa doko desu ka? | [N] | |
| Could you write it down? | 書いていただけますか？ | Kaite itadakemasu ka? | [V] | For prices, times, addresses. |
| Sorry, I don't speak Japanese | すみません、日本語が話せません | Sumimasen, nihongo ga hanasemasen | [V] | |
